# Aspia Update Manager

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-GPL--3.0-green.svg)](LICENSE)

**Aspia Update Manager** — это удобный конфигуратор сервера обновлений для **Aspia 3.x.x**. Инструмент полностью соответствует официальным принципам работы сервера обновлений Aspia и автоматизирует рутинные задачи по управлению релизами, каналами обновлений и цифровыми подписями.

## ✨ Возможности

### 📥 Загрузка новых релизов
- Формирование списка компонентов (`DOWNLOAD_MAP`) с указанием требуемых платформ и расширений инсталляторов.
- Загрузка необходимых релизов Aspia из официального репозитория одной командой с проверкой уже существующих файлов.
- Автоматический расчет SHA-256 хешей для скачанных файлов-инсталляторов.
- Автоматическое формирование JSON-манифеста версии со всеми необходимыми реквизитами.

### 🛠 Управление каналами обновлений
- Создание или сброс JSON-файлов каналов обновлений (с запросом подтверждения при перезаписи существующего файла).
- Установка актуальной версии обновления для канала.
- Создание цепочек обновлений (добавление последовательностей обновлений).
- Удаление правил обновлений
- Просмотр текущей конфигурации канала с удобной сортировкой.

### 🔒 Автоматическая подпись JSON-манифестов
Инструмент автоматически подписывает манифесты версий и каналов после ключевых операций:
- После загрузки релизов и генерации манифеста версии (`download`).
- После создания или сброса канала (`channel create`).
- После установки метки `latest` (`channel latest`).
- После добавления или удаления правила обновления (`channel add` / `channel remove`).

### 🛡 Контроль и тестирование
- Самотестирование конфигурации (`check`) для проверки консистентности всех файлов и корректности подписей JSON-манифестов.
- Автоматическая проверка наличия файла настроек (`.vars`) при запуске с предложением создать его со значениями по умолчанию.

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/lumian/aspia-update-manager.git
   cd aspia-update-manager
   ```

2. Создайте файл настроек по умолчанию:
   ```bash
   ./aspia_manager.py createvars
   ```

3. Отредактируйте файл `.vars` под ваши задачи (см. раздел [Настройка](#-настройка)).

4. Загрузите нужный релиз и настройте канал обновлений:
   ```bash
   ./aspia_manager.py download 3.1.2
   ./aspia_manager.py channel create stable
   ./aspia_manager.py channel stable latest 3.1.2
   ```

## 💻 Использование

Запустите скрипт без аргументов для вывода справки:
```bash
./aspia_manager.py
```

### Управление релизами
```bash
./aspia_manager.py download <версия>   # Скачать файлы, удалить лишнее и создать манифест версии
```

### Управление каналами обновлений
```bash
./aspia_manager.py channel create <канал>              # Создать или сбросить канал (stable, beta, alpha)
./aspia_manager.py channel <канал> latest <версия>     # Установить последнюю версию для канала
./aspia_manager.py channel <канал> add <источник> <цель> # Добавить правило обновления (напр., 3.0.37 @latest)
./aspia_manager.py channel <канал> remove <источник>   # Удалить правило обновления для версии-источника
./aspia_manager.py channel <канал> list                # Показать текущую конфигурацию канала
```

### Проверка и восстановление целостности
```bash
./aspia_manager.py check    # Проверить целостность всей конфигурации репозитория и подписи
./aspia_manager.py resign   # Переподписать все JSON-манифесты в репозитории одной командой
```

## 📖 Параметры команд

| Параметр | Описание | Пример |
|----------|----------|--------|
| `<канал>` | Имя канала обновлений. Допустимые значения: `stable`, `beta`, `alpha`. | `stable` |
| `<версия>` | Версия Aspia в формате `3.a.b`. | `3.1.2` |
| `<источник>` | Версия, с которой выполняется обновление. | `3.0.37` |
| `<цель>` | Целевая версия назначения или специальная метка `@latest`. | `@latest` или `3.1.2` |

### Примеры использования
```bash
./aspia_manager.py createvars
./aspia_manager.py download 3.1.2
./aspia_manager.py channel create stable
./aspia_manager.py channel stable latest 3.1.2
./aspia_manager.py channel stable add 3.0.37 @latest
./aspia_manager.py channel stable list
./aspia_manager.py check
./aspia_manager.py resign
```

## ⚙️ Настройка

Все основные параметры хранятся в файле `.vars` в формате JSON, который находится в той же директории, что и скрипт. Если файл отсутствует, скрипт предложит создать его автоматически.

**Основные параметры `.vars`:**

| Параметр | Описание |
|----------|----------|
| `TARGET_ROOT_DIR` | Корневая директория сервера обновлений. |
| `TARGET_STORAGE_DIR` | Абсолютный путь к директории хранения инсталляторов. |
| `UPDATE_BASE_URL` | Публичный URL-путь к директории `storage`. |
| `ASPIA_SIGNER_PATH` | Путь к утилите `aspia_signer.py` (допускается относительный путь). |
| `PRIVATE_KEY_PATH` | Путь к приватному ключу для подписи манифестов (допускается относительный путь). |
| `DOWNLOAD_MAP` | Словарь, определяющий необходимые компоненты, платформы и расширения файлов для загрузки. |

## 🔑 Автономная подпись файлов (`aspia_signer`)

В комплект входит автономный Python-скрипт `aspia_signer.py`, не привязанный к основной кодовой базе Aspia. Он полностью совместим с командами официального `aspia_signer` и позволяет:
- Генерировать приватный ключ в формате PEM.
- Отображать публичный ключ при создании приватного ключа.
- Подписывать JSON-файлы манифестов в соответствии со стандартами Aspia.
